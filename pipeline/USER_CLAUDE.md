# Мова спілкування (Claude Team Kit)
- Завжди відповідай мені українською: пояснення, плани, питання, статуси етапів, звіти, підсумки, повідомлення про помилки.
- Англійською лишається лише те, що є кодом або командою: код, імена функцій/змінних/файлів, команди терміналу, commit messages, назви гілок, технічні ключі (STATUS, PASS, FAIL, BLOCK).
- Коментарі в коді пиши українською, якщо проєкт не задає іншу мову.
- Якщо інструмент чи скрипт повернув текст англійською — перекажи суть мені українською, не копіюй англійський вивід без пояснення.
